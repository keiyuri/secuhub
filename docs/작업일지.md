### 반영된 변경 내용

**보안**
- `LoginAttemptService`(신규): 로그인 실패 브루트포스 방어. 계정별 실패 횟수를 세어 5회 실패 시
  15분간 잠금. 존재하지 않는 계정에 대한 무작위 실패로 추적 맵을 채워 실제 계정의 잠금 기능을
  무력화하는 "맵 포화 공격"을 막기 위해, 상한 도달 시 단순 차단 대신 **LRU 축출** 방식으로 전환.
- `LegacyAwarePasswordEncoder`(신규): `tb_users.passwd`에 섞여 있는 BCrypt 해시와 레거시 평문
  비밀번호를 모두 처리. 레거시 평문으로 로그인 성공 시 Spring Security의 업그레이드 메커니즘을 통해
  즉시 BCrypt로 재해시.
- `SecurityConfig` / `SecurityUserDetailsService`: 위 두 컴포넌트를 인증 흐름에 연동(계정 잠금 상태
  반영, 패스워드 인코더 교체).
- README에 **게이트 연결의 IP 기반 신뢰 모델**을 명시하고, 배포 시 네트워크 세그먼트 분리가 반드시
  필요하다는 전제 조건을 문서화(애플리케이션 계층 인증이 없는 것이 의도된 설계임을 명확화).

**동시성 / 프로토콜 안정성**
- `GateConnectionRegistryImpl`: `closeConnectionIfCurrent` 추가 — 조회 후 종료하던 2단계 처리를
  원자적 처리로 바꿔, 그 사이 재연결이 끼어드는 레이스 컨디션을 제거.
- `NetCheckJob`: 위 API로 교체해 동일한 레이스 컨디션 대응.
- `ServerModeConfig` / `GateTcpServer`: `idleTimeoutSeconds`(기본 90초) 도입, Netty
  `ReadTimeoutHandler`로 half-open 커넥션(케이블 단절/NAT 타임아웃 등)을 `SO_KEEPALIVE`의 OS 기본
  유휴시간(약 2시간)보다 훨씬 빠르게 정리.
- `PacketDiffer.laneNumbersOf`: 레인 상태 블록 경계 검증을 "첫 바이트만 범위 내"에서 "블록 전체가
  범위 내"로 강화하고, 읽은 레인 번호 값이 유효 범위(1..MAX_LANE_COUNT)인지 검증 — 조작/잘린 패킷이
  레인 라우팅을 깨뜨릴 수 있던 취약점 수정.
- `SpeedGateProtocolConstants.MAX_REASSEMBLY_BUFFER_SIZE`: `MAX_PACKET_LENGTH`와 동일해 여유가
  없던 문제를 `MAX_PACKET_LENGTH`의 2배로 조정.
- `SpeedGatePacketDecoder` → `SpeedGatePacketReassembler`로 이름 변경(책임을 명확히 반영).

**데이터/쿼리**
- `DataReceiveAnalysisRepository` 및 신규 마이그레이션 `V2__fix_dashboard_query_indexes.sql`:
  대시보드 미해결 오류 조회 쿼리에 `resolve_yn='N'` 조건이 누락되어 해결된 오류가 계속 미해결로
  표시되던 버그 수정 + 두 쿼리(`tb_data_rcv_anal`, `tb_opr_status`)의 실제 접근 패턴에 맞는 인덱스
  추가.

**테스트**
- `GateConnectionRegistryImplTest`, `GateConnectionStateTest`, `GateDbWriteQueueTest`,
  `DefaultGatePacketHandlerTest`, `GateTcpServerTest`, `LegacyAwarePasswordEncoderTest`,
  `LoginAttemptServiceTest`, `SecurityConfigTest`, `SecurityUserDetailsServiceTest`,
  `DashboardServiceTest` 등 신규/보강.
